# 🌟 Vaibhav Lakde — Professional Developer Portfolio

A responsive, high-performance **Developer Portfolio Website** engineered strictly using **pure HTML5, CSS3, and Vanilla JavaScript (ES6+)** with zero external frameworks or libraries.

---

## 🛠️ Technology Stack & Core Competencies

- **HTML5**: Semantic landmark structure (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`), accessible ARIA attributes, SVG iconography.
- **CSS3**: CSS Custom Properties (Theme tokens), Flexbox, CSS Grid layouts, mobile-first media queries, dark/light theme switching.
- **Vanilla JavaScript (ES6+)**: DOM manipulation, dynamic text animation, filter tab engines, state persistence via `localStorage`, client-side form validation.
- **Web Content Management (CMS) & Web Authoring**: Experience in dynamic content schemas, structured page publishing, and catalog ingestion workflows.

---

## ✨ Features

1. **Light / Dark Theme Switcher**: Instant theme toggle with state remembered across browser sessions via `localStorage`.
2. **Dynamic Headline Animation**: Smooth typing effect rotating through core specialization roles.
3. **Filterable Skills Matrix**: Categorized view across Frontend Technologies, CMS & Authoring Tools, and Workplace Skills.
4. **Featured Projects Showcase**: Detailed project cards including the **Flipkart Clone & CMS Authoring Console** with architecture modals.
5. **Rotational Shifts & Global Readiness**: Dedicated section outlining 24/7 availability across US, EMEA, and APAC client time zones with disciplined shift handovers.
6. **Accessible Contact Form**: Client-side validation with real-time feedback messages and toast notifications.
7. **Mobile Navigation**: Hamburger navigation with responsive drawer menu.
